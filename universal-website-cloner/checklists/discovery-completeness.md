# Discovery Completeness Checklist

- [ ] Capability report saved (`clone-workspace/_env-check.json`) and MCP availability recorded honestly
- [ ] Authorisation + robots.txt + ToS decisions in `provenance.md`
- [ ] Crawl done; limits and unvisited-URL note recorded
- [ ] sitemap.xml checked; sitemap-only pages visited
- [ ] Navigation, dropdowns/mega-menus, footer, breadcrumbs, language switchers inspected
- [ ] Dynamic route patterns identified (`:slug`, `:id`)
- [ ] Authenticated routes identified; roles listed; inaccessible roles noted
- [ ] Desktop + mobile (+ tablet/laptop if layout differs) screenshots per route
- [ ] Forms inventoried (fields, validation rules, success/error behaviour)
- [ ] Buttons, modals, tabs, accordions, carousels, filters, sort, pagination, search probed
- [ ] Loading / empty / error / success states captured where safely reachable
- [ ] 404 page and error pages captured
- [ ] Design tokens measured; fonts/icons identified
- [ ] Asset inventory complete with licence flags
- [ ] Network behaviour **shape** noted for API-driven pages
- [ ] Third-party widgets (maps, chat, payments, analytics) listed with mock plan
- [ ] Blockers (CAPTCHA/MFA/paywall/geo/rate-limit) listed and raised to the user
