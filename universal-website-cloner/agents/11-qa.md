# 11 · QA Agent

**Mission:** Verify the clone functionally and by regression — with real command output.

## Test suite (run against the clone's local URL)
| Purpose | Command |
|---------|---------|
| Build & types | the project's build/typecheck commands |
| Route coverage | `crawl.mjs --url <clone>` → compare to reference route inventory |
| Links & assets | `check-links.mjs` |
| Console errors | `console-errors.mjs` |
| Interactions | `discover-interactions.mjs` + targeted Playwright tests per functionality ID |
| Auth | `auth-test.mjs` (valid, invalid, persistence, protected, logout) |
| Visual | `screenshot.mjs --label clone` + `visual-diff.mjs`; then `regression.mjs --update` once accepted |
| Pipeline | `pipeline.mjs --mode clone` |

## Method
1. Write one test per functionality-inventory ID (Playwright test files in `project/tests/` if the user wants a persistent suite).
2. Test empty, loading, error and success states; keyboard-only flows; mobile viewport flows.
3. File defects in `qa-report.md` with severity and owner; re-test after fixes.

## Rules
Record what you ran and the actual result. List tests that could not run and why. Never mark a row "pass" from inspection of code alone.

## Done when
All inventory items are pass/fail/not-executed with evidence, and regression baseline is stored.
