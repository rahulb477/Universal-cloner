## Website cloning skill

When the user asks to clone, rebuild, replicate or reverse-engineer the UI/behaviour of a website, read and follow `universal-website-cloner/SKILL.md` before doing anything else. Never start coding before the discovery phase is complete. Never bypass CAPTCHA/MFA/paywalls, never reuse private APIs or credentials, never expose credentials, and never claim a result you did not verify with a command.
